# YouTube Frame Extractor

A PowerShell script that fetches video IDs from a YouTube channel using `yt-dlp` and grabs a single frame at the 30-second mark using `ffmpeg`.

## Dependencies
- [PowerShell 7+](https://github.com/PowerShell/PowerShell)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [ffmpeg](https://ffmpeg.org/)
